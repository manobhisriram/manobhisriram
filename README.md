## 🔷 Featured Projects

### ⚖️ Legal Contract Intelligence Platform
[Repo →](https://github.com/manobhisriram/LEGAL-INTEL-AGENT)

4-agent AutoGen pipeline across 5 LLMs — reviews contracts in under a minute for $0.054 vs 2–4 hours of manual review. Validated across 150+ real contracts. LLM-judge evaluation scored 82.4% across 100 CUAD contracts; adversarial red-teaming cut failure rate from 41% to 9% over 3 rounds. Exposed as 4 MCP servers (17 tools) for natural-language use directly inside Claude Desktop.

`AutoGen` `Claude Sonnet 4.5` `GPT-4o` `Gemini 1.5 Pro` `Milvus` `MCP Servers` `Datadog` `Langfuse`

### 🏥 MedAssist — Clinical Triage Agent
[Repo →](https://github.com/manobhisriram/MEDASSIST-AGENT)

Locally-deployed clinical triage agent for regulated healthcare — zero cloud dependency, zero cost per query. LoRA-fine-tuned Phi-3 Mini on 15K medical QA examples (training loss 1.92→1.21) via Ollama. 5-node LangGraph pipeline with Pydantic-validated, auto-retrying outputs. Ragas-evaluated: 0.92 faithfulness, 0.90 relevancy, 0.85 precision. CI/CD blocks any regression below 0.60 faithfulness.

`LangGraph` `LoRA` `Phi-3 Mini` `Ollama` `LanceDB` `Ragas` `DeepEval`
